# Chapter 1 - Overview & Typology
Sondstrube is an inflected language descended Pasu Muns. It is an inflected language, maintaining a moderately complex morphology. Due to seasonal labor division the language has two evolving noun classes that decline differently from each other, with one retaining high overt grammatical specificity as the other smooths out differences and relies increasingly on word order and context.

# Chapter 3 - Nouns
## Noun Classes
Historically only two distinct classes of nouns existed - inanimate and animate. Over time, as C3 speakers spend nearly half of each year working in separate environments before regrouping for the winter, they developed their own ways of talking about salient nouns, dividing the animate category further into **maritime animate** and **upland animate**.
### Animate Nouns
Identification of either noun class is semantically intuitive for many roots. Animate nouns that belong in the maritime environment are maritime. Animate nouns that belong in the upland environment are upland. However, there are some grey areas, particularly in the different fowl varieties.

| Maritime   | Meaning   |
| ---------- | --------- |
| ponthar    | puffin    |
| pederekhar | guillemot |
| nokuthar   | razorbill |
| lestran    | kittiwake |
| tranhar    | gull      |
BUT:

| Upland    | Meaning      |
| --------- | ------------ |
| fleda     | grouse       |
| brana     | ptarmigan    |
| bropa     | wild chicken |
| dapa      | crow         |
| flana     | hawk         |
| hlundapa  | cormorant    |
| balaflana | gannet       |
Note that the last two on the upland list, cormorants and gannets, are maritime birds, but the roots they are derived from *(dap* and *flan)* are upland roots, therefore the new terms are also upland.

The word for bird itself, *fral*, belongs to the upland class.

Due to social structure and labor division, the maritime and upland nouns classes map fairly cleanly to male and female human terms, respectively.


| Maritime | Meaning |
| -------- | ------- |
| daghar   | man     |
| farlhar  | father  |
| terhar   | brother |

| Upland | Meaning |
| ------ | ------- |
| nora   | woman   |
| snula  | mother  |
| srela  | sister  |
It is important to note that this is a result of women working overwhelmingly in the upland pastures and men working overwhelmingly out at sea, not an inherent association with sex or gender.
### Inanimate Nouns
Inanimate nouns are anything not considered animate.

| Inanimate | Meaning |
| --------- | ------- |
| balu      | blood   |
| gradu     | forest  |
| nratu     | foot    |
| sinu      | star    |

This is fairly straightforward to determine with common sense and basic intuition, although a few key exceptions should be noted.

| Word    | Meaning | Class    |
| ------- | ------- | -------- |
| frena   | river   | upland   |
| sela    | lake    | upland   |
| sondhar | sea     | maritime |

## Number
There are two grammatical numbers - singular and plural. Singular is unmarked, and plural is marked with the letter *n*. It is incorporated into the case endings, so the cases will be presented with both singular and plural versions for clarity.

- *Dlebra -> dlebrna* - a deer -> some deer
- *Tuku -> tuknu* - rock -> rocks
- *Dopkhar -> dopknar* - boy -> boys

Some roots already end in an *n*. Plural endings still add an additional *n*. Keep in mind that two *n*'s are pronounced twice as long as a single *n*.

- *Frena -> frenna* - river vs. rivers
## Case
There are six grammatical cases in C3 that have distinct case endings. Additionally, the case endings change form depending on the class of the noun being declined. Below are the declension tables for each of the three noun classes.

Noun roots ending with a vowel are declined by inserting a *-t-* in between the root and the case ending (i.e. *fla-* -> *flata*).
### Case Endings
**Maritime Animate Case Endings**
Of the three declension paradigms, the maritime retains the oldest animate forms.

| maritime case | singular | plural |
| ------------- | -------- | ------ |
| nominative    | -har     | -nar   |
| accusative    | -i       | -ni    |
| dative        | -nal     | -ennal |
| ablative      | -ruj     | -nruj  |
| genitive      | -u       | -nu    |
| vocative      | -raf     | -nraf  |
Example:
- *Farlhar paki dladru* - Father watches the seal

**Upland Animate Case Endings**
The upland forms are significantly eroded, with the accusative and the genitive having disappeared completely.

| upland case | singular | plural |
| ----------- | -------- | ------ |
| nominative  | -a       | -na    |
| accusative  | -        | -n     |
| dative      | -na      | -ena   |
| ablative    | -o       | -no    |
| genitive    | -        | -n     |
| vocative    | -ro      | -nro   |
Example:
- *Nora ti brop kednrer* - The woman killed that chicken

**Inanimate Case Endings**
The inanimate case endings are descended directly from the historical inanimate endings.

| inanimate  | singular | plural |
| ---------- | -------- | ------ |
| nominative | -u       | -nu    |
| accusative | -i       | -ni    |
| dative     | -of      | -nof   |
| ablative   | -uj      | -nuj   |
| genitive   | -s       | -nes   |
| vocative   | -ro      | -nro   |
Example:
- *Vustnu balani trodfan* - The winds are pushing the waves
### Case Function
Below are brief descriptions of each grammatical case and its function.
#### Nominative Case
The nominative case marks the subject or agent of a phrase. It is the standard citation form for all nouns.
#### Accusative Case
The accusative case marks the direct object or patient of the verb. It also denotes motion toward a noun when combined with various prepositions (see chapter on relational words for more detailed information).
#### Dative Case
The dative case denotes the beneficiary of a verb, and also doubles as a locative case when combined with various prepositions (see chapter on relational words for more detailed information).
#### Ablative Case
The ablative case is used to mark either the source of something (the direction from which something came or an action is performed) or the means (instrument) by which an action is accomplished. In the directional sense, it is often used in conjunction with prepositions and other helper words (see chapter on relational words for more detailed information).
#### Genitive Case
The genitive case can be used to mark the possessor in possessive constructions. Word order flexible, i.e. the genitive marked possessor can come either before or after the possessee, although variation from the default is extremely rare in practice. The default order is \[possessee]\[possessor] so when the possessor comes first it is usually for emphasis or contrast.

- *Kataku farlu batfe sedru* - Father's boat glides well on the water
- *Farlu kataku batfe sedru* - *Father's* boat glides well on the water
#### Vocative Case
The vocative case marks the thing or person being addressed in direct speech.

- *Gemro fi! Buj af fa!* - My daughter! Come to me!
- *Sondraf, nkos mni eltmok!* - O sea, carry us homeward!
- *Terraf fu, tigmun!* - My brother, let us go!
## Personal Pronouns
Personal pronouns in C3 stand in for nouns, and are declined for case, noun class, and grammatical number to reflect the noun they stand in for. The following two tables show the singular and plural paradigms, with each cell showing the forms in the order \[maritime]/\[upland]/\[inanimate].

**Singular Personal Pronoun Declension**

| singular pronouns | 1st person | 2nd person | 3rd person |
| ----------------- | ---------- | ---------- | ---------- |
| nominative        | far/fa/fu  | gar/ga/gu  | ar/ra/ru   |
| accusative        | fi/fi/fi   | gi/ga/gi   | ri/ru/ri   |
| dative            | fa/fa/fo   | ga/ga/go   | ra/ra/ro   |
| ablative          | fer/fe/fer | ger/ge/ger | er/re/er   |
| genitive          | fu/fi/fis  | gu/ga/gas  | ru/ru/rus  |
| vocative          | fa/fo/fo   | ga/go/go   | ra/ro/ro   |
**Plural Personal Pronoun Declension**

| plural pronouns | 1st person    | 2nd person          | 3rd person    |
|-----------------|---------------|---------------------|---------------|
| nominative      | mnar/mna/mnu  | dlonar/dlona/dlonu  | hnar/hna/hnu  |
| accusative      | mni/mun/mni   | dloni/dlon/dloni    | hni/han/hni   |
| dative          | mna/mna/mno   | dlona/dlona/dlono   | hna/hna/hno   |
| ablative        | mner/mne/mner | dloner/dlone/dloner | hner/hne/hner |
| genitive        | mnu/mun/muns  | dlonu/dlon/dlons    | hnu/han/hans  |
| vocative        | mna/mno/mno   | dlona/dlono/dlono   | hna/hno/hno   |

Examples:

- *Mnal strubga* - You are speaking to me
- *Fo re strubnrer* - He was speaking about her
- *Ar nanad dragnar* - He is very strong

While there is generally a strong correlation between upland and feminine, and maritime and masculine, the animacy classes are NOT merely a reflection of gender.

One pointed manifestation of this fact is that little boys are still addressed as "ga" and referred to as "ra", as they accompany the women and girls to the upland pastures every year. Once a young adolescent boy starts going out to sea with his father and uncles, the community naturally shifts to addressing him as "gar" and referring to him as "ar" , reflecting the domain he is newly associated with.

Similarly, an adult male who for whatever reason ends up working more closely with the women inland might be referred to as "ra", and in some cases it may be used in a derogatory fashion. Although rare, a woman who goes to sea often might be referred to as "ar".

The above described pronoun usage customs also extend to regular noun conjugation with personal names or other personal referents.
# Chapter 4 - Verbs
Verb inflection (conjugation) in C3 has only two tense distinctions and a single class of irregular verbs that follow a predictable pattern. Conjugations encode grammatical person and number, as well as tense.

The root form of a verb is obtained by subtracting the *-e* from the end.

- *hlaje -> hlaj* - to drift
- *duke -> duk* - to row
- *leke -> lek* - to be
## Present Tense
The following table illustrates the present tense endings for each person/number combination.

| Present Tense | Singular | Plural |
|---------------|----------|--------|
| 1st Person    | -fi      | -mun   |
| 2nd Person    | -ga      | -dlon  |
| 3rd Person    | -ru      | -fan   |
## Past Tense
The following table illustrates the past tense endings for each person/number combination.

| Past Tense | Singular | Plural |
|------------|----------|--------|
| 1st Person | -nref    | -nrem  |
| 2nd Person | -nrag    | -nrod  |
| 3rd Person | -nrer    | -nraf  |
## Imperative Verbs
Imperative verbs are used to express will or desire, often in the form of a command or behest. When addressing a single person the verb stem is used without any ending. When addressing multiple people in the second person the ending *-dlon* is used. When expressing ideas like "let's go" (first person plural) the ending *-mun* is used.

The *j* in *J* verbs (discussed in the next section) does not alternate to a *d*, even when a verb ending is applied.

- *Tig!* - Go!
- *Planddlon!* - Sit (you all)!
- *Dbajmun.* - Let us continue
- *Kej ri!* - Kill him!
## *J* Verbs
Verbs ending in *j* conjugate differently from other verbs. When conjugating such a verb, the *j* changes to a *d* based on historical sound changes.

- *daj* -> *dadfi* - I give
- *skaj -> skadnrag* - You knew
## Copular Expressions
Copular expressions are phrases where a subject is described by an adjective or another noun (X is Y). In Sondstrube the verb of being can be omitted in the third person singular, and is often the preferred way of speaking.

- *Ra pkolota* - She is pretty
- *Oko sa glera gema ga?* - That girl is your daughter?
## Negation
The main negative particle is *du*, meaning "no".

- *Mnal du kerru* - I don't like it
- *Sketi du hnaktnrag skape* - You did not remember to close the door
- *Ar du begle dragnar* - He is not strong enough
### Never & Negative Indefinites
The word for "never" is *deket*. It is used together with *du* - on its own it means "ever", often used when posing questions. Its negated use is shown below.

- *Deket du frosfi* - I never sleep

The negative particle combines with interrogative particles to form negative indefinites.

- *Duki du fednrer* - He did not eat anything
- *Duki du litnref* - I did not see anything
- *Duklar dragni keli du litnrer* - Nobody saw the big fish
## Directional Productivity
C3 speakers use spatial and directional helper words to create phrasal verbs on the fly and specify trajectory and relative position.
### Directional Compounds

- *Daghar nkognol tradru* - The man goes uphill.
- *Rtagnar nkofren frohudfan* - Salmon swim upriver
### Phrasal Verbs
Directional words such as *nko, fru, elt, grod, etc.* can be used in combination with almost any verb to modify or specify its sense. Prepositions can also be repurposed as phrasal verb particles, such as *suk* or *nunan*. In such uses 

- *Af skalati elt spundnrem* - We traveled toward the mountain (*elt spunde*)
- *Hluni suk brosnref* - I drank all the water

Note that the meaning conveyed by some such particles can often extend beyond their literal or spatial meaning, for example *suk brose* carries a sense of drinking out all of a liquid from a drinking vessel.
## Turning Verbs Into Nouns (Derivation)
Sondstrube verbs can be easily nominalized by simply declining the infinitive form of the verb. As with other nouns ending in a vowel, infinitive verbs used nominally are declined by inserting a *-t-* in between the root and the case ending..

- *Strubeti hnu bnernref* - I learned their speech

The ending *-a* can be attached to verb roots to denote a person or thing that performs the verb. As noun, this then gets declined as appropriate.

- *Nedanar* - Water-goers
# Chapter 5 - Modifiers
Sondstrube distinguishes between adjectives and adverbs, the former for modification of nouns and the latter for modification of verbs, adjectives, and other adverbs.
## Adjectives
Adjectives are used to describe the qualities of a noun they precede. They adhere to specific noun agreement rules. A handful of core adjectives exist as their own roots, but the majority of adjectives in Sondstrube are derived from nouns using productive derivational morphology.
## Deriving Adjectives From Nouns
Here are some examples of noun-derived adjectives.

- *lnohl -> lnohladar* - swanlike
- *tan -> tanad* - milk-like
- *dik -> dikad* - ridgelike
- *bard -> bardso* - coastal
- *tan -> tanso* - milky
- *dik -> dikso* - ridged, ridge-covered
- *vust -> vustso* - windy

The ending *-ad* denotes something to the equivalent of "-like" in English - a quality of being "like" the noun. The ending *-so* indicates the quality of said noun, i.e. "wind -> windy", "blood -> bloody", etc.
## Adjective Agreement With Nouns
Adjectives must agree with the nouns they modify in class, number, and grammatical case. In other words, the case endings should match on both the adjective and the noun.

Adjectives have their own set of case endings largely distinct from those of nouns.

| Adjective Cases | Maritime | Upland | Inanimate |
| --------------- | -------- | ------ | --------- |
| Nominative      | -ar      | -a     | -u        |
| Accusative      | -i       | -      | -i        |
| Dative          | -a       | -a     | -o        |
| Ablative        | -er      | -e     | -er       |
| Genitive        | -u       | -      | -s        |
| Vocative        | -a       | -o     | -o        |
The initial vowel of any adjective case ending replaces the *o* of adjectives formed with the derivational ending *-so*. All other adjectives ending in a vowel are declined by inserting a *-t-* in between the root and the case ending.

For the plural forms of the endings in the above table, *-n-* is inserted between the root and the case ending regardless of adjective type.

Examples:

- *Bigsar lekfi* - I am whole/healthy
- *Bigsona norna fafenna* - The healthy women are beautiful
- *Kdata nora tand tran litnrer* - The strong woman saw a white gull
- *Dragnar daghar nedru* - The big man goes on the water
- *Dragnnar dagnar nedfan* - The big men go on the water
## Demonstratives
Demonstratives behave like adjectives and must agree with the modified noun in case, noun class, and grammatical number.

| Demonstratives | Maritime | Upland | Inanimate |
| -------------- | -------- | ------ | --------- |
| Nominative     | star     | sa     | tu        |
| Accusative     | sti      | so     | ti        |
| Dative         | sta      | sa     | to        |
| Ablative       | ster     | se     | ter       |
| Genitive       | stu      | so     | tes       |
| Vocative       | sta      | so     | to        |
The plural forms of the above demonstratives are formed by inserting *n* right after *st-, s-,* and *t-* respectively for each class.

- *Litga so nor?* - Do you see that woman?
- *Ngagu stu dopku sap blatni ferlni tkoladnrer* - That boy's shadow fell across the dry leaves
## Possession With Pronouns
Possession is indicated by marking the possessor in the genitive case and placing it before or after the possessee in the sentence. This means that genitive personal pronouns can be used to express possession.

- *Farlhar kataki fu trannrer* - Father made my boat (my = maritime)
- *Nora trend ru spennrer* - The woman gave birth to her child (her = upland)
- *Mokuj ga budnrag* - You came from your home (your = upland)
- *Snulna fu dlapi da dadnref* - I gave your net to my mother (my = maritime, your = upland)

The genitive pronoun's class should match the class of the possessor, not the thing being possessed.

The grammatical number of the possessed object continues to be marked on the object, while the grammatical number of speakers is inherently indicated by the genitive pronoun.

- *Brosi han litmun* - We see their drink (their = upland)
- *Brosni ru litmun* - We see her drinks (her = upland)

In order to omit the overt possessed noun, it must be replaced with the dummy "pro-form" particle *do*, which declines for case and agrees with noun class. See the chapter on relative clauses for a full discussion of the pro-form particle.

- *Di gu litfi* - I see yours (di = accusative, gu = maritime genitive)
## Participial Adjectives
Both the present participle (ending with *-le*) and the past participle (ending with *-nre*) may be used as adjectives. When modifying nouns, participles decline according to the ordinary adjective agreement paradigm.

Similar to adjectives formed with the derivational ending *-so*, participial adjectives' final vowel *-e* is replaced by any initial vowel in the adjectival case ending.

- *Gbostnru bdeku i glendof duhlagnu plannrer* - The forgotten village sat lifeless in the valley
- *Bratleni kelni komnnref* -I took the hanging fish

**When used predicatively with *leke*, participles remain uninflected and do not agree with the subject.**

- *Af karatof fru plannre lekfi* - I am sitting (sat down) near the boat.
- *Dukle, nunan ngagi skalats nednrem* - Rowing, we went (on water) into the shadow of the mountain
## Adverbs
Adverbs can be formed from virtually any adjective by attaching the ending *-fe*.

- *Vakfe dukfi* - I row quickly
- *Elti salno brufe protnref* - I sadly lost my eye to a falcon
- *Lnohladfe i karatof sednrer* - He "swanlikely" went on the water in a boat

The *-fe* ending replaces the final vowel of adjectival roots, with certain exceptions. Generally:

- *balsar -> balsfe* - bloody -> bloodily
- *gnolsar -> gnolsfe* - hilly -> in a hilly manner
- *pkolor -> pkolfe* -> pretty -> prettily

Some examples of exceptions:

- *hlar -> hlafe* - wet -> wetly
- *brur -> brufe* - sad -> sadly
## Comparatives & Intensifiers
When comparing two things, the compared object is placed in the dative case. Virtually all adjectives can take the suffix *-(a)p* before the declined ending. The noun being compared to is in the dative case and preceded by the preposition *af*.

- *Star daghar kdapar af fa* - That man is stronger than I
- *Sa nora sit pkolopa af san norna tat* - This woman is prettier than that woman

The expressions *nanad* (very) and *dosi* (a little) can be used to modify adjectives or other adverbs. *Nanuj* (by much) and *dosuj* (by little) can intensify comparative adjectives.

- *Nanad dregnreta lekfi* - I am very tired
- *Dosi brur lekfi* - I am a little sad
- *Nanuj fafenapa af ra lekga* - You are way more beautiful than her

*Dosap* + adjective can be used to express "less adjective" in comparisons.

- *Dosuj dosap dragnar ran lekfi* - I am a little less strong than he

The superlative is expressed using the suffix *-muk* on the adjectives before the declined endings.

- *Fafenmuka lekga* - You are the most beautiful
- *Farlhar nanuj kdamukar* - Father is by far the strongest
- *Tandmuki palti litnrem!* - We saw the whitest snow!
# Chapter 6 - Relational Words
## Spatial Relations
Case endings combine with prepositions and other adpositions to arrive at specific spatial and directional meaning. First some key case ending meanings will be discussed in isolation, followed by the prepositions and helper words paired with different case endings.
### Cases With No Prepositions
**Accusative Case**
With certain location names, such as *mok* for "house/home", the accusative case is used without prepositions to imply direction toward said object.

- *Moki tigmun* - We are going home

If any ambiguity is present, the appropriate preposition is introduced for clarity.

**Ablative Case**
By itself the ablative denotes a general "from X".

- *Mokuj budnrag* - You came from home
### Case Switching Prepositions
The preposition specifies the spatial relationship, while the case ending specifies whether the trajectory is moving toward that relationship, remaining within it, or moving away from it.

| Accusative Case | Dative Case | Ablative Case    |
| --------------- | ----------- | ---------------- |
| Motion toward   | No motion   | Motion away from |
Many prepositions can take any of the three case endings noted above. These are called case-switching prepositions. Any applicable case restrictions will be noted below.
#### *I* - "In/Inside"
Denotes "in" or "inside".

- *Tuki i gosti fotnref* - I placed the stone into the chest
- *I mokof lekga* - You are inside the home
- *I mokuj tignrem* - We went from inside the home

#### *Suk* - "Out"
Designates the location on the exterior or outside of something.

- *Suk moki budnref* - I came outside the home
- *Suk mokof dlon nkebnrem* - We waited for you outside the home
- *Suk mokuj budnrag* - You came from outside the home

#### *Af* - "Nearby/At"
Denotes "at" or "in the vicinity of". Used for place names or general locations.

- *Oko tignrag af gler?* - You went over to the girl?
- *Af mokof nko plannre lekru* - He is standing at/near the home.
- *Dagnar af dragner skunaguj sednraf* - The men boated from the vicinity of the large settlement

#### *Ko* - "On"
Designates the location of the surface.

- *Pdakdlon dlapni ko karati?* - Will you all throw the nets onto the boat?
- *Ko tukof fru plannre lekru* - He is sitting on the rock
- *Frala ko tukuj bofrnrer* - The bird hopped off of the rock

#### *Nunan* - "Under"
Literally an adjective meaning "low", *nunan* used as a preposition denotes the location beneath something

- *Sipa nunan pondi bgannrer* - The mouse crawled under the bed
- *Fadu nunan ferlnof hlu lekru* - The ground underneath the leaves is wet
- *Sipa nunan ponduj suk bgannrer* - The mouse crawled from under the bed
#### *Dat* - "Above"
*Dat* means "at high elevation" when used as an adjective. Repurposed as a preposition it means "above".

- *Tukni dat gnoli pdaknrem* - We threw stones over the hill
- *Dapa dat bdekof bralenru* - A crow flies above the village
- *Fumnu dat skalatuj hladfan* - The clouds drift in from above the mountains
#### *Son* - "Between"
*Son* literally means "center" or "middle". When *son* is used as a relational preposition, the nouns always take the genitive ending - literally formulating "in the middle of X and Y" where X and Y are genitive-marked.

- *Frala soni tuks u fla bralenru* - The bird flies between a stone and a tree
- *Sonof Farlu u Snul fru plannre lekfi* - I am sitting between Father and Mother
- *Dopkhar sonuj flanons mokns budnrer* - The boy came out from among the wooden homes
#### *Hok* - "Behind"
*Hok* means "behind."

- *Biki hok sketi fotnref* - I placed the spear behind the door
- *Droga ski hok flatof pkrasru* - The fox is hiding behind the tree
- *Hok snuguj budnraf* - They came out from behind the raft
#### *Bred* - "In Front Of"
*Bred* means "in front of".

- *Rtaghar bred skadi fu nko bofrnrer* - A salmon jumped up in front of my face
- *Bred mokof nkebmun* - We are waiting in front of the home
- *Bred fejlabo bofrnrer* - He leapt from before the bear (out of the way of the bear)
### Fixed-Case Prepositions
#### *Laf* - "Around"
*Laf* means "around" and only takes the accusative case.

- *Kraganna laf gnoli bralenfan* - Eagles fly around the hill
#### *Sap* - "Across"
Coming from the verb root *sape*, this preposition literally means "cross/tack", as in a tack performed while sailing or boating. It takes the accusative case.

- *Sap tuki nibi dkloknref* - I broke the branch across a stone
#### *Fo* - "About/For"
*Fo* means "about" or "for" depending on context. It uses the ablative case when used in the "about" sense, and the dative case in the "for" or benefactive sense.

- *O dlon strubnrem* - We spoke about you (all)
- *Biki o ga tarnnref* - I made the spear for you

Keep in mind in every-day discourse, the latter example can also be expressed without the explicit *o* similar to an English alternative phrasing:

- *Biki ga tarnnref* - I made you the spear
## Temporal Relations
before, after, during, until
There are a few prepositions used in conjunction with case endings to express temporal relations.

*Hok* and *bred* are repurposed here as "after" and "before" respectively.

- *Hok tignrag, torsi gan dadnref* - Before you went I gave you food
- *Bred ski nkorenga, kadga feje* - After you arise you can eat

The verb *sbej* "to last" has the present participle *sbedne* which means "during".

- *Spedne fedga, frosnref* - While you ate, I slept

The word *pud* means "until".

- *Bgor elti treknre pud ski nkorenfi* - Keep an eye open until I wake up
### Temporal Expressions
The preposition *nunan* is used with *horn* ("moon") or *dun* ("sun") dative case to express things like "last night" or "during the day", etc.

- *Nunan hornof bokni ndupnrem* - Last night we caught some codfish
- *Nunan hornof bokni ndupmun* - Tonight we will catch some codfish

Note that *nunan hornof* is used for both "last night" and "tonight", with the verb tense disambiguating.

- *Nunan dunof af skalati tradfi* - Today I am walking to the mountain
- *Nunan dunof frosnref* - Yesterday I slept
## Instrumental Vs. Comitative
The ablative case is used for both instrumental (with tool/means) and comitative (with whom) constructs, but a key difference exists.

Instrumental constructs are formed using the ablative case only:

- *Dlebrn biknuj kednrem* - We killed the deer(pl) with spears

Comitative constructs employ the word *ska* together with the ablative case:

- *Ska Snulo spundnrem* - We traveled with Mother

Further examples:

- *Pakni ska Farlruj dlondbikuj slertdlon* - You are hunting seals with Father using a rope-spear
- *Kelni dlapuj ndupnref* - I caught fish with a net
## Other Abstract Relations
because of, despite, for


| Expression  | Meaning |
| ----------- | ------- |
| *o nupof*   | because |
| *du dladle* | despite |
- *Fednref o nupof mgotar leknref* - I ate because I was hungry
- *Ga glodfi du dladle ri dkloknrag* - I love you even though you broke it
# Chapter 7 - Questions & Relative Clauses
## Interrogatives
C3 has a handful of interrogative particles, as shown in the below table.

| Lemma | Gloss |
| ----- | ----- |
| klar  | who   |
| ku    | what  |
| kfar  | where |
| fker  | why   |
| kek   | how   |
| kdun  | when  |
These particles are used to ask a variety of questions. Question word order simply takes the verb and moves it to the very beginning of the phrase, right after the interrogative particle. Note that *klor* and *ku* both decline using the adjective declension patterns.

- *Klar kednrer sti dagi?* - Who killed this man?
- *Kli kednrer star daghar?* - Whom did this man kill?

Furthermore, *ku*'s use is extended as meaning "which" when declined in agreement with a noun, acting as a sort of determiner. *Ku* takes the adjectival case endings when used as a determiner, with the vowel *u* getting replaced by the endings as appropriate.

- *Kar daghar kednrer ru?* - Which man killed her?
- *Af ke noro dkernnrag ti?* - Which woman did you get this from?

Note that when used as an interrogative determiner, *ku* declines for any of the three classes, while in its function as the interrogative particle meaning "what" it only gets declined in the inanimate case.

Further interrogative examples:

- *Kundug dorkmun?* - When are we leaving?
- *Fker gbostnrod brate nko fadn?* - Why did you forget to hang up the rabbits?
## Yes/No Questions
The affirmative particle is *ba*. The negative particle is *du.*

Yes or no question word order also places the verb at the beginning of the phrase. Often times yes/no questions are also marked explicitly using the *oko* "whether" particle - often reduced to *ko* - right before the verb.

- *Oko kadga frohuj?* - (Whether) you can swim?
- *Oko hlernrer i hornof?* - Did it rain last night?
## Relative Clauses
Relative clauses are used to provide further identifying information regarding a noun than a simple adjective construction could provide. Relative clauses in C3 are opened using a fully declined class-specific dummy "pro-form" particle. The pro-form particle paradigm is shown in the below table.

| dummy noun | maritime | upland | inanimate |
|------------|----------|--------|-----------|
| nominative | dar      | da     | du        |
| accusative | di       | do     | di        |
| dative     | dar      | da     | do        |
| ablative   | der      | de     | der       |
| genitive   | du       | do     | dos       |
| vocative   | da       | do     | do        |
In relative clauses *dar* is paired with *ku* (what/which): *kudar*. *Kudar* declines based on its role *inside* the relative clause

Examples:

- *Daghar kudar nardn ndupru fan buje reknrer* - The man who catches trout told me to come
- *Fejlab kudo litnref dorknrer* - The bear that I saw left
- *Nora, kudo hughar frosru, nunan gradof glapru* - The woman whose son sleeps sings in the forest

The final bound of the relative clause is typically marked by the usual verb in the final position.

- *Nupu, fo der keli ga fednref, leknrer mgotar leknref* - The reason I ate your fish was that I was hungry
# Chapter 8 - Information Structure & Focus
The default word order in C3 is \[subject]\[object]\[verb]. Due to extensive case marking word order is flexible, however, and the parts of a sentence can be rearranged to serve topicalization and focus.

In general, extra information gets placed between the object and the verb by default (\[subject]\[object]\[extras]\[verb]) but when the less-central information becomes long-winded or cumbersome, all or part of it can be fronted or topicalized to "get it out of the way".

Times of occurrence almost always gravitate toward the topic slot by default.

- *Nunan dunof nani hlers litnref* - Yesterday I saw a lot of rain

## Topicalization & Focus
C3 uses the initial slot for both focus and topicalization.

Topicalization simply establishes what is being talked about up front. Especially common in narratives, verbs are often fronted to express "and then this happened". Compare:

- *Tuku fru blotruj tkoladnrer* - A stone fell from the sky (a stone down from the sky fell)
- *Tkoladnrer fru tuku blotruj* - Then a stone fell from the sky (fell down a stone from the sky)

Focus is used when a specific part of a phrase or sentence is being emphasized. Since the focus element occupies the same slot as the topicalized element, speakers rely on context to infer whether something is being focused or simply topicalized.

Of the following examples, only the first is in neutral order. The rest use focus to highlight different words.

- *Nora ti nkorati fednrer* - The woman ate that walnut
- *Ti nkorati nora fednrer* - The woman ate *that walnut*
- *Fednrer nora ti nkorati* - The woman *ate* that walnut

Note that emphasis of the element which occupies the focus slot by default relies simply on prosody (spoken) emphasis, i.e.:

- Nora *ti nkorati fednrer* - The *woman* ate that walnut

The focus-based use of the sentence-initial slot is especially clear in contrastive statements.

- *I frenna, du i sondnal rtagi safennref* - I saw salmon in the river, not the sea
## Coordination
Some coordinating conjunctions include:

- *u* - and
- *a* - and (list, non-contrastive)
- *po* - but
- *so* - or

Examples:

- *Farlhar a Snula ski skorennraf u dorknraf* - Father and Mother got up and left
- *Nunan skerno dunof rtagi, talati, miki, nard, a boki i sondnal ndupnrem, po dan duki du litnrem* - Yesterday we caught salmon, char, herring, trout, and cod in the sea, but now we did not see anything
